# Расчёт расхода фасадной краски

**Разработка интернет-приложений (РИП) 2025**  
**Автор:** Борисова К.А.

---

## 📋 О проекте

Разработанное приложение позволит заказчикам краски рассчитывать необходимое количество краски для покраски фасада при заданных характеристиках по укрывистости, а производителям краски завершать или отклонять обрабатываемые заявки.
